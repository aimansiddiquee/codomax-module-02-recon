# Linux Command Cheat Sheet

| Task | Command |
|---|---|
| Where am I | `pwd` |
| List files | `ls -la` |
| Change directory | `cd /var/log` |
| Create folder / file | `mkdir dir`, `touch file` |
| Copy / move / delete | `cp`, `mv`, `rm` |
| Read file | `cat`, `less`, `tail -f` |
| Search text | `grep -i "error" file` |
| Find file | `find / -name "*.conf"` |
| Permissions | `chmod 755 file`, `chown user:group file` |
| Users | `whoami`, `id`, `sudo`, `passwd` |
| Processes | `ps aux`, `top`, `kill PID` |
| Network | `ip a`, `ping`, `ss -tuln`, `curl` |
| Updates | `sudo apt update && sudo apt upgrade` |
| Firewall | `sudo ufw status`, `sudo ufw allow 22` |
